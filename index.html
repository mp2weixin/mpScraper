1启动本地采集应用

  1. 双击 app.exe 启动本地微信公众号采集应用。
  2. 如果应用启动失败，可手动点击 ca-cert.p12 安装代理 HTTPS 证书。
  3. 如果启动界面显示 http server { http://127.0.0.1:8081 }，说明服务已正常运行，可在浏览器打开访问地址。
  4. 打开后台后输入账号和密码登录，即可进入采集管理界面。
文章列表查询提示词示例 调用文章列表工具函数，查询“本地生活”等 3 个公众号最近一周的数据，筛选包含指定关键词的文章，并按发布时间、阅读数、点赞数或评论数排序。
文章详情查询提示词示例 帮我查找 id=1 的文章内容。这里的 id 来自文章列表接口返回的数据。

2提取要采集的公众号文章

  1. 打开 PC 微信，访问需要采集的公众号，任选一篇文章打开，并手动刷新微信内置浏览器。
  2. 访问 公众号管理页面，正常情况下会出现对应公众号信息。
  3. 进入“公众号管理”标签页，可继续执行增量采集、全量采集或自定义时间段采集。
  4. 文章采集完成后，进入“公众号文章”标签页，配置文章详情、转发、点赞、评论等后续采集任务。

3批量导入公众号

  1. 如果已知公众号名称，并且已经登录订阅号，可手动批量导入要采集的公众号。
  2. 导入后复制公众号链接，在微信内打开链接，任选一篇文章打开，并刷新微信内置浏览器。
  3. 当“公众号管理”标签页中的心跳状态显示为“可用”时，表示该公众号可以发起采集。
  4. 如果状态过期，可点击“续期”按钮，系统会通过自动化 RPA 流程续期，状态恢复后即可继续使用。

4任务与中台分析

任务管理

在“任务管理”标签页中查看历史采集操作记录，便于追踪每次采集任务的执行情况。

中台分析

中台分析页面上半部分展示系统运行状态，下半部分展示当前系统配置。

  1. 如果暂时不采集，可点击“关闭代理”，让工具与微信 PC 断开连接；再次使用前请重新开启代理服务。
  2. 签名默认有效期为 1 小时。如需继续使用，请联系 QQ。

5开启签名自动续期/模拟采集

采集依赖微信登录令牌，默认有效期为 30 分钟。开启自动续期后，系统会在检测到即将到期时自动执行续期流程。

  1. 本地安装 Python，建议使用 Python 3.12，并在安装时勾选“将 Python 加入 PATH 环境变量”。
  2. 在命令行中安装脚本依赖包，可使用清华大学 Python 镜像源加速安装。
  3. 依赖安装完成后，重启应用：关闭命令行窗口，再双击 app.exe 重新打开。
  4. 模拟采集依赖这几个插件，强烈建议安装上这个，这样如果接口被限流可以通过使用这个方式采集.
pip install uiautomation pyperclip pyautogui -i https://pypi.tuna.tsinghua.edu.cn/simple

6关键词监控与 MCP 服务

系统支持关键词词库管理，可基于关键词批量采集或增量采集公众号推文。同时提供 MCP 接口服务，便于本地智能体调用文章数据进行初步资料分析。

MCP：查询公众号文章列表

取到文章列表后，可根据返回的 id 查询详情。列表查询支持以下参数：

参数 说明 示例
公众号名称数组 指定需要查询的公众号。 ['本地生活', '中药指南']
关键词数组 指定文章需要包含的关键词。 ['GLP-1', '肥胖']
日期限制 查询指定日期之前或指定范围内的文章。 2006-01-01
排序字段 默认按发布时间 created_at 降序，也可按阅读、点赞或评论数排序。 read_num、old_like_num、comment_count
返回数量 设置本次抓取返回的文章列表数量。 20
偏移量 设置当前获取记录的偏移量，默认从 0 开始。 0

MCP：查询公众号文章详情

告诉智能体需要查询的文章数值编号，即可返回 Markdown 格式的文章详情。
